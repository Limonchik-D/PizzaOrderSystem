## 1. Состав проекта

- `PizzaOrderSystem.csproj` — конфигурация проекта **.NET 8.0** с пакетом `Microsoft.Data.Sqlite`.
- `Program.cs` — точка входа ASP.NET Core Minimal API, раздача статического фронтенда, REST API (`/api/menu`, `/api/sizes`, `/api/orders`, `/api/orders/{id}/status`, `/api/staff`) и режим запуска автотестов (`--test`).
- `Models/DomainModels.cs` — модели предметной области и DTO.
- `Data/PizzaRepository.cs` — слой доступа к SQLite, транзакционное оформление заказов, расчёт европейского НДС (10%) и бесплатной доставки от €25.00, машина состояний статусов заказа.
- `Tests/SelfTestRunner.cs` — набор модульных и интеграционных тестов бэкенда и БД SQLite.
- `Database/schema_and_seed.sql` — DDL-схема (7 нормализованных таблиц) и реалистичные тестовые данные (9 видов пицц, 3 размера, 3 роли персонала, 4 клиента и 4 заказа в разных статусах).
- `pizza_orders.db` — готовый предзаполненный файл базы данных SQLite.
- `wwwroot/index.html` — адаптивный корпоративный веб-интерфейс в стандарте ЕС (каталог, чекаут с GDPR, трекинг заказа с аудит-логом и панель персонала).

## 2. Инструкция по запуску и тестированию

1. Убедитесь, что установлен **.NET 8.0 SDK** (`dotnet --version`).
2. Распакуйте архив и откройте терминал в папке `PizzaOrderSystem/`.
3. **Запуск встроенных автотестов C# + SQLite:**
   ```bash
   dotnet run -- --test
   ```
4. **Запуск веб-приложения:**
   ```bash
   dotnet run
   ```
5. Откройте в браузере адрес, указанный в консоли (обычно `http://localhost:5000` или `http://localhost:5180`).
