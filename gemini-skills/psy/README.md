# Psychological Reflection — Gemini Skill package (v1.0)

**Import:** на странице Gemini «Навыки» выберите «Создать → Загрузить» и укажите ZIP. В корне архива находится `SKILL.md`, остальные `.md` — в `references/`. Убедитесь, что итоговые имя/описание/инструкции в предпросмотре корректны.

**Ручной вариант:** если доступна только форма из трёх полей, скачайте текст полей из сопровождающего файла `gemini-manual-fields.md`, который поставляется отдельно от архива. Важно: при ручном создании дополнительные модули **не** будут загружены автоматически; для полной версии используйте импорт ZIP или «Заменить навык».

## Область применения
Навык поддерживает личную рефлексию, безопасную самопомощь и психообразование. Не ставит диагнозы и не проводит специализированные клинические процедуры. Используйте с обезличенными примерами; не загружайте чувствительные документы без необходимости.

## Основные файлы
- `SKILL.md` — выбор режима, правила, маршрутизация.
- `references/method-selection.md` — выбор подхода.
- `references/safety.md` — кризисы и границы.
- `references/01-cbt.md` … `06-emdr.md` — шесть отдельных модулей.
- `references/evidence-register.md` — официальные рекомендации, исследования и ограничения.
- `references/quality-and-communication.md` — контроль ложной уверенности и качества общения.
