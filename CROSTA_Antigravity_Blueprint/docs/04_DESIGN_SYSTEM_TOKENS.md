# 04. Дизайн-система и карта анимаций (EU Food-Tech Warm Palette)

## 1. Цветовые токены (CSS Custom Properties)

Запрещено использовать стерильно-белый `#FFFFFF` в качестве основного фона. Вся палитра строится на тёплом пергаменте/беже для светлой темы и тёплом эспрессо-угле для тёмной темы:

```css
:root {
  --bg-canvas: #F5EFE6;        /* Тёплый пергамент / бежевый фон страницы */
  --bg-surface: #FBF8F3;       /* Карточки, модальные окна, сайдбар */
  --bg-elevated: #EBE3D5;      /* Вторичные плашки, чек, активные фильтры */
  --border-subtle: #DFD5C5;    /* Тёплая деликатная граница */
  --text-primary: #1C1917;     /* Глубокий тёплый графит (контраст > 13:1) */
  --text-secondary: #57534E;   /* Вторичный текст (контраст > 5.8:1, WCAG AA) */
  --accent-primary: #B91C1C;   /* Терракотово-томатный акцент */
  --accent-hover: #991B1B;
  --accent-bonus: #15803D;     /* Оливково-изумрудный для бонусов и статусов */
}

[data-theme="dark"] {
  --bg-canvas: #141210;        /* Тёплый угольный фон */
  --bg-surface: #1E1B18;       /* Карточки и панели */
  --bg-elevated: #282420;      /* Вторичные блоки и строки таблиц */
  --border-subtle: #36302A;    /* Тёплая тёмная граница */
  --text-primary: #F5EFE6;     /* Тёплый кремовый текст (контраст > 13:1) */
  --text-secondary: #A8A29E;   /* Приглушённый тёплый серый */
  --accent-primary: #DC2626;
  --accent-hover: #EF4444;
  --accent-bonus: #22C55E;
}
```

## 2. Типографика
- Заголовки и интерфейс: `Plus Jakarta Sans` / `Inter` (вес `600`–`700`, плотный трекинг `-0.02em`).
- Цены, артикулы `SKU`, номера заказов `ORD-2026-XXX`, бонусные баллы: `IBM Plex Mono` с `font-variant-numeric: tabular-nums`.

## 3. Карта осмысленных анимаций (GSAP + CSS)
1. **Hero & Promo Stagger (`gsap.from`):** при загрузке главной страницы заголовок и 3 карточки акций появляются каскадом (`stagger: 0.07`, `y: 14 -> 0`, `opacity: 0 -> 1`, `duration: 0.45`, `ease: "power2.out"`).
2. **Menu Scroll Reveal (`ScrollTrigger.batch`):** карточки меню плавно проявляются группами при прокрутке (`once: true`), без повторного дёргания вверх-вниз.
3. **Micro-interactions:**
   - Кнопка «В корзину»: лёгкий тактильный отклик (`scale(0.97)` при нажатии) + плавное появление бейджа количества в корзине.
   - Переключатель светлой/тёмной темы: плавная смена `background-color` и `color` (`180ms ease`).
   - Счётчик бонусов и итога чека: плавная подсветка при изменении суммы списания бонусов.
4. **Доступность:** оборачивать все GSAP-вызовы в `gsap.matchMedia()` с проверкой `(prefers-reduced-motion: no-preference)`.
